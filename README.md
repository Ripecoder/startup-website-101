# Nexulith

Software that captures factory product data the moment it exists — QR codes, barcodes,
photo-based capture, and fully custom entry workflows.

**One click away from fully automating your work.**

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Landing page: hero, three ways we help, sales & availability |
| `pricing.html` | Plans (Pilot / Production / Enterprise) and FAQ |

## Run locally

Any static server works, for example:

```bash
python -m http.server 8000
# or
npx serve .
```

Then open <http://localhost:8000>.

## Structure

```
index.html      landing page
pricing.html    pricing + FAQ
styles.css      shared theme (dark canvas, red brand, white actions)
script.js       nav, mobile menu, scroll reveals
favicon.png     logo
robots.txt      crawler rules
sitemap.xml     sitemap
```
